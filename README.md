# Synchronous Sequential Circuit with JK Flip-Flops

An academic digital-logic design project involving a synchronous finite-state machine. The design documentation describes a 7-state system, 3 external input signals, and 2 output signals.

## Design topics

- Synchronous finite-state machines (FSMs)
- JK flip-flops and combinational logic
- State-transition analysis
- Karnaugh maps for Boolean-expression simplification
- Circuit simulation in CircuitVerse

## Project materials

The repository currently includes the project documentation. For a more reviewable portfolio entry, add the following artifacts where available:

- A readable state diagram
- The state-transition table
- Simplified Boolean equations for the JK inputs
- A screenshot of the simulated circuit

## How to review

Read the included project document for the design explanation. If a CircuitVerse project link is added, open it to inspect the circuit and its simulation. Do not treat a PDF-only copy as a directly runnable simulation.

## Technologies and concepts

CircuitVerse, digital logic, JK flip-flops, Karnaugh maps, synchronous FSM design.
